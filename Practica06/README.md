# Práctica 06 — Secuencia de pantallas móviles y desktop

## Descripción

Esta práctica transforma el modelo de negocio CANVAS de Epic Games en una propuesta de experiencia de usuario para móvil y escritorio. El prototipo organiza la navegación alrededor de dos perfiles —jugador y creador— y muestra las pantallas compartidas necesarias para acceder a cada experiencia.

La entrega incluye **18 pantallas**: seis compartidas, seis para jugadores y seis para creadores. Cada pantalla tiene versiones móvil y desktop, para un total de **36 diseños en SVG y PNG**. Los formularios, compras, permisos y demás acciones se presentan como una simulación académica; no se conectan a servicios reales.

## Probar el prototipo

**[Abrir la Práctica 06 publicada](https://devfntxy.github.io/Practicas_Integradora_230892/Practica06/)**

También puedes abrir el archivo [index.html](index.html) localmente en Chrome o Edge. No requiere instalación. En el prototipo puedes:

1. Explorar el catálogo de pantallas organizado por rol.
2. Seleccionar una pantalla para abrirla en el recorrido interactivo.
3. Avanzar mediante las acciones disponibles, volver a pantallas anteriores, reiniciar o saltar a otra pantalla.
4. Cambiar entre las propuestas visuales móvil y desktop.
5. Descargar los sketches en SVG y PNG.
6. Consultar los flujos interactivos de Archify y la relación entre el CANVAS y las pantallas.

## Roles y recorridos

- **Pantallas compartidas:** bienvenida, inicio de sesión, creación y verificación de cuenta, recuperación de acceso y selección de rol.
- **Jugador:** descubrimiento y búsqueda de juegos, consulta de detalles, compra simulada y biblioteca.
- **Creador:** panel, proyectos, creación y preparación de una ficha, envío a revisión y consulta de estado y métricas.

Los flujos principales conectan el acceso con la experiencia del rol elegido. Las rutas alternativas, cancelaciones y regresos se pueden explorar en el prototipo.
