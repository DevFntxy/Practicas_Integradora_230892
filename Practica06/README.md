# Práctica 06 — Secuencia de pantallas móviles y desktop

Esta práctica presenta una propuesta académica para Epic Games con dos roles y 18 pantallas: seis compartidas, seis para jugadores y seis para creadores. Incluye sketches móviles y de escritorio, un prototipo navegable y diagramas interactivos de Archify.

## Abrir la práctica

Abre [index.html](index.html) en Chrome o Edge para recorrer la secuencia, probar las acciones de cada pantalla y cambiar entre los diseños móvil y desktop. No requiere instalación.

Los archivos y recursos de la práctica están organizados en [diagrama/](diagrama/). Consulta la [documentación completa](diagrama/README.md) para ver el inventario de pantallas, los flujos, las instrucciones de reproducción y los resultados de verificación.
